# Level 0 → Level 1

## Objective
Find the password for Bandit Level 1 after logging in as Bandit Level 0.

## Commands Used
ls  
cat readme

## Explanation
- Logged into the Bandit server as `bandit0`.
- Listed files in the home directory using `ls`.
- Found a file named `readme`.
- Used `cat readme` to display its contents.
- The output contained the password for Level 1.
