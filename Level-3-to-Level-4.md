# Level 3 → Level 4

## Objective
Find the password for Bandit Level 4. The password is hidden inside a directory.

## Commands Used
ls -la  
cd inhere  
ls -la  
cat "...Hiding-From-You"

## Explanation
- Listed files in the home directory using `ls -la`.
- Found a directory named `inhere`.
- Navigated into the directory using `cd inhere`.
- Listed all files, including hidden ones, using `ls -la`.
- Found a hidden file named `...Hiding-From-You`.
- Used `cat` to read the file and obtain the password.

## Password
2WmrDFRmJIq3IPxneAaMGhap0pFhF3NJ

## What I Learned
- How to navigate directories using `cd`
- How to view hidden files
- How to read files with unusual names
