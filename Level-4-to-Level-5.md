# Level 4 → Level 5

## Objective
Find the password for Bandit Level 5. The password is stored in a human-readable file inside a directory.

## Commands Used
ls  
cd inhere  
file ./*  
cat ./-file07

## Explanation
- Listed files in the home directory using `ls`.
- Entered the directory `inhere` using `cd inhere`.
- Used `file ./*` to check the type of all files in the directory.
- Identified the human-readable file named `-file07`.
- Used `cat ./-file07` to read the file safely.
- The output contained the password for Level 5.

## Password
4oQYVPkxZ0OEOO5pTW81FB8j8lxXGUQw

## What I Learned
- How to identify file types using the `file` command
- How to locate human-readable files
- How to handle filenames starting with a dash
