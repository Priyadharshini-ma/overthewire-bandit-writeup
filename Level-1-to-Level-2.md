# Level 1 → Level 2

## Objective
Find the password for Bandit Level 2. The password is stored in a file with a special name.

## Commands Used
ls  
ls -la  
cat ./-

## Explanation
- Listed files using `ls`.
- Used `ls -la` to view hidden and detailed file information.
- Identified a file named `-`.
- Since the filename starts with a dash, used `cat ./-` to correctly read the file.
- The output contained the password for Level 2.
