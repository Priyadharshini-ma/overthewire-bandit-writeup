# Level 17 → Level 18

## Objective
Find the password for Bandit Level 18 by comparing two files.

## Commands Used
ls  
diff passwords.new passwords.old

## Explanation
- Listed the files in the directory using `ls`.
- Found two files: `passwords.new` and `passwords.old`.
- Used the `diff` command to compare both files.
- Identified the line that differed between the two files.
- The changed line contained the password for Level 18.
