# Bandit Level 0

## Objective
Log into the Bandit server using SSH.

## Login Command
ssh bandit0@bandit.labs.overthewire.org -p 2220

## Explanation
- Used SSH to log into the Bandit server as user 'bandit0'.
- This level is an introduction to connecting to a remote system.

## What I Learned
- How to use the 'ssh' command
- Basic remote login syntax
