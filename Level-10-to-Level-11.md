# Level 10 → Level 11

## Objective
Find the password for Bandit Level 11. The password is encoded in Base64 format.

## Commands Used
ls  
base64 -d data.txt

## Explanation
- Listed files in the directory using `ls`.
- Identified the file `data.txt`.
- Used `base64 -d` to decode the Base64-encoded content of the file.
- The decoded output revealed the password for Level 11.
