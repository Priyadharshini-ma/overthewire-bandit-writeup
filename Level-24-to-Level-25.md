# Level 24 → Level 25

## Objective
Retrieve the password for Bandit Level 25 by brute-forcing a PIN-protected service running locally.

## Commands Used
cd /tmp  
nano brute.sh  
chmod +x brute.sh  
./brute.sh  

## Explanation
- Moved to the `/tmp` directory to create a custom script.
- Created a brute-force script (`brute.sh`) to try all possible PIN combinations.
- Made the script executable.
- Executed the script to interact with the local service.
- The correct PIN revealed the password for the next level.
